## 📚 Repository Overview
This repository contains all laboratory experiments and weekly lab exercises for the **R Programming** course. Each experiment demonstrates practical implementations of data manipulation, statistical analysis, visualization, machine learning, and big data handling in R.

---

## 🔬 Lab Experiments

| Experiment | Title | Description | Tech / Packages |
| :---: | :--- | :--- | :--- |
| **EXP 1** | Data Cleaning & Missing Values | Ingesting & inspecting PRSA Air Quality dataset, handling NA/NaN/NULL, imputation, and data visualization. | `dplyr`, `tidyr`, `skimr`, `ggplot2` |
| **EXP 2** | Control Flow for Data Cleaning | Conditional transformations, outlier handling, and pipeline optimization on Heart Disease & Adult datasets. | `dplyr`, `naniar`, `skimr`, `microbenchmark` |
| **EXP 3** | Data Ingestion & Transformation | Downloading UCI Online Retail dataset, multi-format export (CSV, RDS, Parquet), and data restructuring. | `readr`, `readxl`, `writexl`, `dplyr`, `arrow` |
| **EXP 4** | Image Classification (Deep Learning) | Binary image classification (Cars vs Planes) using fully-connected Deep Neural Network with Keras 3. | `keras3`, `tensorflow`, `jpeg` |
| **EXP 5** | Social Network Analysis | Graph modeling, centrality metrics, Hubs/Authorities (HITS), and community visualization. | `igraph` |
| **EXP 6** | Statistical Analysis | Descriptive & inferential statistics, hypothesis testing (ANOVA, t-test), and distribution analysis on Palmer Penguins. | `palmerpenguins`, `tidyverse`, `lsr`, `car` |
| **EXP 7** | Customer Segmentation & ML | RFM feature engineering, K-Means & Hierarchical clustering, Silhouette validation, and classification modeling. | `factoextra`, `cluster`, `randomForest`, `plotly` |
| **EXP 8** | High-Performance Big Data Analytics | Ingesting & benchmarking large-scale NYC Taxi dataset, parallel processing, and performance comparison. | `arrow`, `data.table`, `duckdb`, `furrr` |

## 💻 Weekly Lab Work

| Lab Work | Topic | Highlights |
| :---: | :--- | :--- |
| **Lab 1** | R Basics & Variables | Variable assignment (`<-`, `=`, `->`), data types, basic arithmetic. |
| **Lab 2** | Vector Arithmetic | Calculations with data vectors, scalar operations, power and arithmetic. |
| **Lab 3** | Missing Data Handling | NA checks (`is.na`), handling missing values in summary statistics (`na.rm = TRUE`). |
| **Lab 4** | Control Structures | `for` loops, `while` loops, conditional `if-else` branching. |
| **Lab 5** | Sequences & Series | Sequence operators (`:`), `seq()`, `rep()`, vector indexing. |
| **Lab 6** | Lists in R | List creation, indexing, merging (`c()`), and list-to-vector conversion (`unlist()`). |
| **Lab 7** | String Formatting | Output formatting with `print()`, `cat()`, and `paste()`. |
| **Lab 8** | String Operations | Text pattern replacement using `sub()` and `gsub()`. |
| **Lab 9** | Data Frames | Operations on data frames, indexing, subsetting, summary metrics on datasets (`MASS::painters`). |

## 🚀 How to Run
1. Clone this repository:
   ```bash

   ```
2. Open the Jupyter Notebooks (`.ipynb`) in Jupyter Lab, VS Code, or Google Colab.
3. Open the R scripts (`.R`) in RStudio or run via R command line:
